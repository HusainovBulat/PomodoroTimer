# PomodoroTimer

Компактный таймер поверх всех окон (WPF, .NET 10).

## Управление
- `+9` (или Enter / +) — новый отрезок: верхний таймер с начала, к общему +длина отрезка, запись в список
- `▶ / ⏸` (или Пробел) — старт / пауза обоих таймеров
- после истечения всего времени отсчёт продолжается: красным показывается перебор `+м:сс`; `+9` добавляет отрезок, и перебор вычитается из него
- `↺` — сброс
- поле справа — длина отрезка: `9`, `12:30`, `0:45`, `1.5`
- перетаскивание — за любое пустое место; правая кнопка — скрыть список / выход
- длина отрезка и позиция окна запоминаются (%AppData%\PomodoroTimer\settings.txt)
